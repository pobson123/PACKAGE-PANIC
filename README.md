# PACKAGE PANIC!

A colourful, no-dependency browser arcade game. Parcel physics and the warehouse are drawn procedurally on a canvas, so it runs without downloading assets.

## Run it

1. Open a terminal in this folder.
2. Run `npm start`.
3. Visit `http://localhost:4173`.

## Controls
* **WASD** to move
* **Mouse** to aim
* **E** to grab/drop
* **Left Click** to throw
* **Shift** to sprint
* **Escape** to pause
